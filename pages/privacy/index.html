TabClipboard / Privacy

Privacy policy

Effective September 10, 2026

TabClipboard moves HTTP and HTTPS links between your open Chrome tabs and system clipboard. It performs these operations locally and only when you request them.

  1. 01

    Information handled

    TabClipboard can process open-tab URLs and text from your system clipboard. URLs and clipboard text may contain personal or sensitive information.

  2. 02

    User-requested actions

    When you select Copy open tabs, TabClipboard reads the URLs of open tabs, keeps HTTP and HTTPS URLs, and writes them to your clipboard as one URL per line.

    When you select Open clipboard links, TabClipboard reads clipboard text, identifies valid HTTP and HTTPS URLs, and opens them as background tabs. Blank, malformed, and non-web entries are skipped.

    TabClipboard does not perform either operation automatically.

  3. 03

    Data practices

    Processing occurs locally in your browser. TabClipboard does not transmit tab URLs or clipboard contents to the publisher or any external service. It does not collect, retain, sell, or share this information, and it does not maintain its own stored copy after an action completes.

  4. 04

    Chrome permissions

    tabs
    Reads open-tab URLs and creates background tabs.
    clipboardRead
    Reads clipboard text after you request that links be opened.
    clipboardWrite
    Writes tab URLs after you request that they be copied.

  5. 05

    Tracking and services

    The extension does not use analytics, advertising, accounts, tracking technologies, remote APIs, or remotely hosted executable code.

  6. 06

    This policy website

    This website adds no analytics, cookies, or client-side scripts. It is hosted by GitHub Pages, so GitHub may process technical request information under its Privacy Statement.

  7. 07

    Changes and contact

    This policy will be updated if TabClipboard's data practices change. The effective date above will identify the latest version.

    For privacy questions, contact the publisher through GitHub Issues.
